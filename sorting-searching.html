Searching algorithms

Linear search

How does it work?

  • Start from the beginning of a list of items and iterate through the list until you find the searched for item

Examples:

  • Search for 45 – Start at 11, then check 27, then 18, then 45, then stop – item found
  • Search for 100 – Start at 11, then check 27, then 18, then 45, then 1, then 98, then 33, then 22, then 48, then stop – item NOT found

Binary search

How does it work?

  • Starting with a sorted list look at the middle value (midpoint)
  • Determine if you need to go higher or lower
  • Repeat these steps until you either find the searched for value or have checked through the whole list

Sorting algorithms

Selection sort

How does it work?

  • Find the smallest item in the list. Swap the smallest item with the item in the first slot.
  • Then move on to the second slot, and repeat until the whole list is sorted

Quick sort

How does it work?

  • Quick sort is a “divide-and-conquer algorithm” i.e. split the array into two smaller parts, and get each part right.
  • Here’s how it works:
    • Pick an item in the array, called “the pivot”. (It doesn’t matter what item, you will probably be told what e.g. the last item).
    • Make up two arrays of values, above and below the pivot.
    • Repeat the above two steps on each of these arrays etc.
